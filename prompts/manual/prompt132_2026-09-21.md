## Updated Design

additionally, some new changes are in progress.

- the duplicati daemon is now running as a systemd service
- the unit file, /usr/lib/systemd/system/duplicati.service, specifies the calling user and group as a new, dedicated duplicati user and duplicati group.
- some of the default values for the duplicati service are stored in the /etc/default/duplicati file.
- the duplicati user is a system user that currently has a shell assigned for development and testing, but will ultimately be a system service owner only.
- the duplicati user has a home directory containing the following files:
  - /home/duplicati/.config/Duplicati/.env file contains an environment variable definition of `SETTINGS_ENCRYPTION_KEY` for the backup encryption.
  - /home/duplicati/.config/Duplicati/Duplicati-server.{backup,sqlite,sqlite-shm,sqlite-wal} files
  - /home/duplicati/bin/duplicati-wrapper.bash wrapper script that is called by the systemd unit file to launch the duplicati service.
- the wrapper script in the duplicati /home/duplicati/bin/ directory is a symlink to the actual script which is in the juniper-ml git repo: /home/pcalnon/Development/python/Juniper/juniper-ml/scripts/duplicati-wrapper.bash
- the current version of the wrapper script is a working draft that hasn't been hardened or refactored for production use.
  - e.g., functions haven't been created to address common code blocks, security audits haven't been performed, etc.
- values used by the wrapper script can be received in the following ways:
  - the /etc/default/duplicati file defines the DAEMON_OPTS constant that is passed via the unit file to the wrapper script as a command line parameter.
  - additional command line parameters are parsed after DAEMON_OPTS has been parsed, if present.
  - the contents of the /home/duplicati/.config/Duplicati/.env file are parsed and all defined constants are exported.
- the pcalnon user is a member of the duplicati group, and permissions should be set to allow pcalnon to have read, write, and execute access as appropriate for all backup-related files and scripts.
- the backup destination for duplicati is: /mnt/Backups/Ubuntu/Dropbox/Backups/Yamaguchi/
- the /dev/sda1 partition is mounted at the /mnt/Backups/ directory.
- the /dev/sda1 partition is a different physical disk from the drive partition mounted at /home.
- the backups sent to the /mnt/Backups/ mounted destination directory is a backup instance maintained in a separate, but still on host, disk
- the /mnt/Backups/Ubuntu/Dropbox directory is a live dropbox directory that syncs only the contents of /mnt/Backups/Ubuntu/Dropbox/Backups/ with cloud hosted, dropbox storage.
- the contents of the backup destination need to be at least writeable and executable by the duplicati user so backup files can be written be successfully.
- the contents of the backup destination need to be at least readable and executable by the pcalnon user so dropbox sync will be successful.
- the synced copy of the /mnt/Backups/Ubuntu/Dropbox/ directory maintains a cloud-hosted backup instance.
- as in the original design, a dedicated backup script will create compressed, encrypted, tar archives written to two external usb drives.
- this script should be modified to perform this backup on a preset schedule when the valid USB drives are detected as mounted.
